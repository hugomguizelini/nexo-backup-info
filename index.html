Nexo Backup

Aplicativo pessoal para guardar cópias de segurança criptografadas no Google Drive do próprio titular. Não oferece cadastro nem serviço ao público.

A rotina solicita a permissão drive.file para criar e acessar os arquivos de backup que ela própria cria ou que o titular autoriza especificamente para este aplicativo.

O conteúdo é criptografado antes do envio ao Google Drive. A rotina de backup é separada das integrações de uso cotidiano do assistente Nexo.
